# PCB_Business_Card


## final requirements 

1. battery powerd
2. Fluid Simulation
3. pcb USB
4. RTC
5. to have the device act as a MSC(Mass Storage Class) device so the content of the display can be updated easily
6. to have provision for oled 
7. NFC

## Technical Specs
1. double sided pcb, 2 layer pcb, 
2. final led count 252 
3. LED coulour yellow or white
4. 2 led controller ic :TM1640 : LED Matrix Controller
5. PCB USBc port 
6. rp2350a mcu 
7. NFC : ST25TN01K
8. battery charging module : tp4056
9. IMU : qmi8658 
10. External Flash 
11. Coin cell : lir2032
12. MOQ : 5
